## Recent updates worth watching

- **Dynamic workflows in Copilot CLI and the Copilot app** (Oct 1, 2026): define an orchestration in code that combines automated steps with one or more agents, running sequentially, in parallel, or both. Also available in the GitHub Copilot SDK. [Changelog](https://github.blog/changelog/2026-10-01-dynamic-workflows-in-copilot-cli-and-the-copilot-app)
- **GitHub async merge API generally available** (Oct 1, 2026): merge individual or stacked pull requests, or add them to a merge queue, asynchronously. Submit with `PUT`, then poll with `GET`. It is now the recommended way to merge pull requests programmatically. [Changelog](https://github.blog/changelog/2026-10-01-github-async-merge-api-generally-available)
- **Actions retention now covers checks, runs, and statuses** (Oct 1, 2026): these records follow the same retention setting as artifacts and logs; public repositories are capped at 90 days. [Changelog](https://github.blog/changelog/2026-10-01-actions-retention-now-covers-checks-runs-and-statuses)
- **GitHub Copilot app for Beginners: Run several agents at once**: a GitHub Blog walkthrough for newcomers. [GitHub Blog](https://github.blog/ai-and-ml/github-copilot/github-copilot-app-for-beginners-run-several-agents-at-once/)
